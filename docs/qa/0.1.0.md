## Окружение и ограничения

Эмулятор: Android 16 / API 36, ARM64, 828 × 1792, плотность 320 dpi. Симулятор: официальная Companion-заготовка pyatv 0.14.5 с двумя исправлениями тестовой среды, описанными в [руководстве разработчика](../DEVELOPMENT.md#сквозной-тест-android).

Команды направлялись только на симулятор. Сопряжение и управление настоящим Apple TV, разные версии tvOS и физический Android-телефон в этом прогоне не проверялись. Непрерывный HID-трекпад, Siri и ИК-управление в эту версию не входят.
